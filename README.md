# LeiloesTDSat

## Sobre o projeto

O LeiloesTDSat é um sistema desenvolvido em Java para auxiliar no gerenciamento de uma casa de leilões. O projeto permite o cadastro e a consulta de produtos, utilizando um banco de dados para armazenar as informações do sistema.

## Tecnologias utilizadas

- Java
- MySQL
- NetBeans
- JDBC
- Git e GitHub

## Banco de dados

O sistema utiliza o MySQL para armazenamento e gerenciamento dos dados.

## Versionamento

O projeto é versionado utilizando Git e disponibilizado em um repositório público no GitHub.
